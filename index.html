Publications

Bounded-Memory Aggregate Query Processing on Streaming Temporal Graphs
Tianyi Gao, Hongchao Qin, Haotian Jiang, Guang Zeng, and Rong-Hua Li. CIKM 2026, Oral Presentation.
Abstract:

Time-window aggregate queries over temporal graph streams are important for agent memory, communication monitoring, and knowledge-base analytics, but exact processing becomes costly as timestamped edges accumulate. We propose CAMRS, a budget-decoupled multi-resolution sketch that assigns fine-grained CMS buckets and coarse HLL segments according to their different budget needs. Space-Saving label tracking further supports label-filtered predicates. A closed-form COUNT error bound shows that temporal resolution is the key accuracy lever and enables a reliability-aware exact fallback. On six real-world temporal graphs with 60K–17.8M edges, CAMRS reduces COUNT error by up to 29.7× and predicate error by up to 7.9×, while reducing worst-case tail error by up to 667×.

MemDTG: Dynamic Temporal Memory Graphs for Evidence-Admissible Agent Memory
Yaxin Deng, Hongchao Qin, Tianyi Gao, Guang Zeng, and Rong-Hua Li. CIKM 2026.
Abstract:

Long-term agent memory is an online, non-monotonic retrieval problem: new interactions may reinforce, contradict, supersede, specialize, or expire earlier memories. We propose MemDTG, a dynamic temporal memory graph that treats memory as temporal evidence admission. It separates immutable episodes from a mutable entity–state graph and a memory-evolution graph over assertion versions. A slot-local resolver and deterministic commit rules update lifecycle states, valid intervals, and typed evolution edges. At read time, query constraints are compiled before ranking, and QV-CTW retrieves evidence only inside the legal temporal subgraph. Evidence certificates record selected facts, sources, roles, and rejected alternatives. On LongMemEval and LoCoMo, MemDTG achieves the best LLM-judge accuracy and Citation F1, reducing stale-answer errors by 61.7% and future leaks by 80.1%.
